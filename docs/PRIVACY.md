# 개인정보 처리 설계

이 문서는 구현된 처리 흐름을 설명하며 실제 개인정보 처리방침의 법률 검토를 대신하지 않습니다.

## 수집과 목적

- 위치 검색어·좌표·격자: 선택한 지역의 예보 생성(요청 처리 중)
- 체감 성향·활동 목적: 화면의 맞춤 외출 점수 계산(요청 처리 중)
- 즐겨찾기·최근 위치: 브라우저 `localStorage`에만 저장

이 서비스는 이메일·로그인·구독 정보를 현재 수집하거나 발송하지 않습니다.

## 보관과 삭제

- 예보 API 응답은 서버 DB에 사용자별로 저장하지 않으며, bounded 캐시의 TTL 이후 만료됩니다.
- 브라우저에 저장된 즐겨찾기·최근 위치는 브라우저 설정에서 직접 삭제할 수 있습니다.
- 운영 전환 시 기존 구독·메일 이력은 Flyway V3에서 일괄 삭제합니다.

법정 보존의무나 분쟁 대응 보존이 필요한 기관 도입에서는 보존 근거, 기간, 접근권한과 파기 절차를 별도로 확정해야 합니다.
