# 개인정보 처리 설계

이 문서는 구현된 처리 흐름을 설명하며 실제 개인정보 처리방침의 법률 검토를 대신하지 않습니다.

## 수집과 목적

- 이름: 이메일 브리핑 표시
- 이메일: 날씨 알림 발송과 구독 식별
- 선택 위치·좌표·격자: 지역별 예보 생성
- 알림·체감 설정: 개인화된 발송
- 플랫폼 사용자 ID: 구독 소유권 확인

구독 API는 필수 동의를 검증하고 서버가 관리하는 동의 버전과 동의시각을 기록합니다.

## 보관과 삭제

- 구독 해지는 알림 발송을 중단하고 해지시각을 기록합니다.
- 사용자는 로그인 후 내 데이터 완전삭제를 요청할 수 있습니다.
- 완전삭제는 사용자 레코드뿐 아니라 해당 이메일의 메일 발송이력도 함께 삭제합니다.
- 운영 로그에는 원문 이메일을 남기지 않습니다.

법정 보존의무나 분쟁 대응 보존이 필요한 기관 도입에서는 보존 근거, 기간, 접근권한과 파기 절차를 별도로 확정해야 합니다.
