# 날씨한편 제품·API 로드맵

## 현재 결론

핵심 서비스 운영에는 현재 등록된 API로 충분합니다. `WEATHER_API_KEY` 하나가 단기예보와 초단기실황을 모두 지원하므로 현재 날씨 기능을 위해 새 키를 발급할 필요가 없습니다.

## 이번 고도화 기획: Weather Window

날씨한편의 핵심을 ‘정보를 더 많이 보여주기’에서 ‘오늘의 결정을 더 빨리 돕기’로 바꿉니다. 시간별 예보를 최대 3시간 단위로 묶어 각 시간의 강수확률·강수형태·풍속·기온·습도를 함께 점수화하고, 가장 점수가 높은 연속 시간창을 카드 하나로 보여줍니다.

- 웹: 시간별 막대와 `HH:mm–HH:mm · 점수`를 먼저 노출하고, 추천 시간을 기존 일정 분석기에 한 번에 넘깁니다.
- 메일: 같은 `TODAY'S CALL` 문장과 외출 점수·자료 상태를 먼저 보여줘 받은 편지함에서도 5초 안에 행동을 결정하게 합니다.
- 투명성: 통계적 확률을 가장하지 않고 기상청 원천자료 상태를 별도 표기하며, 새 외부 API 없이 현재 데이터로 동작합니다.
- 실패 기준: 시간별 자료가 없거나 형식이 깨지면 카드를 숨기고 기존 예보·오류 안내를 그대로 유지합니다.

## API 없이 먼저 개선할 항목

1. 현재 관측과 1시간 예보의 오차를 저장해 지역별 신뢰도를 계산합니다.
2. 검색→날씨 확인→구독 전환을 익명 지표로 측정하되 이메일·정확한 위치는 분석 도구로 보내지 않습니다.
3. 외부 API별 지연시간·fallback 비율·메일 성공률에 운영 경보 기준을 설정합니다.
4. 실제 사용 로그가 쌓인 뒤 자주 쓰는 위치와 시간대를 기반으로 화면 순서를 개인화합니다.

새 API는 기능 수를 늘리기 위해 추가하지 않고, 사용자 수요와 기존 데이터로 해결할 수 없는 문제가 확인될 때만 도입합니다.
